# Roteiro de Redes

Roteiro de estudos de Redes de Computadores em 5 sessões: comunicação de dados, modelo OSI, TCP/IP, LANs e WANs, elementos de interconexão, Ethernet, par trançado, cabeamento estruturado, padrão 802.11 e cálculo de endereços IP.

Cada módulo tem explicação, pontos-chave para a prova e exercícios com correção automática. O módulo de IP inclui exemplos resolvidos, exercícios de cálculo, um gerador de exercícios aleatórios e uma calculadora de sub-rede.

A aba **Questões para Estudo** traz um simulado com 20 questões difíceis de múltipla escolha (IP, IPv4/IPv6, NAT, DNS, cabeamento estruturado e TCP/IP), cada uma com a resolução do material de estudo e a explicação da pegadinha.

O site é um único arquivo (`index.html`), sem dependências de build.
